# Repository Structure Guide

This document describes the organization of the repository and the purpose of its main files and directories.

The repository is organized to separate the main simulation, result visualization, supporting analysis tools, project assets, and generated simulation outputs.

## 1. Directory Overview

```text
Convolution_Codes/
│
├── conv_code_project.py
├── performance_gaussian_graph.py
├── performance_laplace_graph.py
│
├── Images/
│
├── analysis/
│   ├── channel_distributions/
│   └── optimization_func_analysis/
│
├── sim_results/
│
├── Simulation_results_gaussian_*.npz
├── Simulation_results_laplace_*.npz
│
├── Convolutional_Codes_Project_Report_Hebrew.pdf
├── requirements.txt
├── README.md
└── .gitignore
```

*Note: The tree is illustrative. The exact filenames and number of result files may vary as the project evolves.*

## 2. Main Simulation and Visualization Scripts

### `conv_code_project.py`

The main simulation entry point.

It implements the simulation workflow for evaluating convolutional coding performance over Gaussian and Laplace noise channels.

### `performance_gaussian_graph.py`

Loads simulation data and visualizes performance results for the Gaussian noise channel.

### `performance_laplace_graph.py`

Loads simulation data and visualizes performance results for the Laplace noise channel.

The visualization scripts are separate from the main simulation, allowing previously generated datasets to be analyzed without necessarily rerunning the simulation.

## 3. `Images/`

Contains project-related visual assets, including:

- Project infographic displayed in the README.
- Example simulation performance graphs.
- Plots illustrating the Gaussian and Laplace channel distributions.

These assets support the presentation and interpretation of the project.

## 4. `analysis/`

Contains supporting analysis scripts that complement the main simulation.

### `channel_distributions/`

Contains Python scripts for constructing and plotting Gaussian and Laplace probability distributions.

These scripts support the analysis and visualization of the noise models used in the simulation.

### `optimization_func_analysis/`

Contains analyses of alternative implementations of selected mathematical operations:

- `bin_to_dec_func.py` — Binary-to-decimal conversion.
- `l1_metric_func.py` — L1 metric calculation.
- `l2_metric_func.py` — L2 metric calculation.

The purpose of these scripts is to investigate computational efficiency and alternative implementations using Python and NumPy operations.

## 5. `Sim_results/`

Dedicated to newly generated simulation result files.

Keeping new outputs in this directory prevents the repository root from accumulating files generated by repeated simulation runs.

The directory is intended for generated outputs rather than the repository's reference datasets.

## 6. Reference Simulation Datasets

Example `.npz` datasets are maintained separately from newly generated outputs.

These files allow the visualization scripts to demonstrate the analysis workflow using existing simulation results.

Their filenames and locations must match the input paths configured in the corresponding visualization scripts.

## 7. Project Report

### `Convolutional_Codes_Project_Report_Hebrew.pdf`

Contains the detailed technical report, including the theoretical background, mathematical derivations, algorithm development, simulation results, graphs, and conclusions.

The report is the primary reference for the project's detailed theoretical and technical discussion.

## 8. Dependencies and Documentation

- **`requirements.txt`** — Lists the Python packages required by the project.
- **`README.md`** — Provides the project overview, key features, and quick-start instructions.
- **`docs/simulation_guide.md`** — Explains installation, simulation execution, visualization, and debugging.
- **`docs/repository_structure.md`** — Describes the repository layout and the purpose of its main components.
- **`.gitignore`** — Specifies files and directories that Git should exclude from version control.

## 9. Debugging Artifacts

CSV files are used for debugging and detailed inspection of simulation data when required.

They are not intended to be generated during every standard simulation run. Debugging artifacts should be kept separate from the normal simulation output workflow.
